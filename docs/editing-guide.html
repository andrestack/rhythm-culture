How it works

Two paths to the live site

A normal change

Start to finish, about five minutes

Claude never makes up dates, prices or payment links. If something is missing, it asks.

  1. Ask. “Add a post: Term 1 drum classes start Monday 2 February in Palmwoods. Use this photo.”

  2. It makes the change on your PC. It gets the latest site first, writes the post and shrinks the photo.

  3. It shows you. The page opens in the app. Read it like a customer. Not right? Say what to change.

  4. Say “save it”. It saves a draft to GitHub.

  5. Say “publish”. The live site updates a couple of minutes later.

Once per computer · about 20 minutes

Set up your computer

We do this together on the call. Every installer: default options.

  1. A GitHub account. I add you to the website. You accept the invite email.

  2. Git for Windows from git-scm.com.

  3. Node 24 from nodejs.org. Pick 24, even if a newer one is offered.

  4. GitHub CLI from cli.github.com.

  5. The Claude desktop app from claude.ai/download. Sign in.

Then

Paste this into Claude

  1. Open Claude, then the Code tab.

  2. Choose your Documents folder.

  3. Paste the text. Sign in to GitHub when a window asks.

From then on, open Claude on the rhythm-culture folder. Something stopped working? Type /rc-setup.

✦ When to call me

Most days you won't need me. These are the days you will.

Call me straight away

  • The site is down, blank or broken after a publish. I put the last version back first.
  • A form didn't send, or enquiries stopped arriving.
  • A payment link charges the wrong amount, or a customer can't pay.
  • Claude asks you to paste a password, code or token. Don't. Send me a screenshot.
  • Claude says git or GitHub is “in a state”, or /rc-setup can't fix it.

Everything else

Ask me first, or just do it

Claude will say “this one needs André” when it does.

Ask me before you start

  • Changing a form: its questions, the booking terms, where enquiries go.
  • A page's web address, deleting pages or products, changing many pages at once.
  • Anything new: online bookings, an events calendar, a newsletter sign-up.
  • Design beyond words and photos: layouts, colours, fonts, the menu.
  • Your domain, email, or logins for GitHub, Vercel or Stripe. Legal wording.

No need to call

  • Typos, class times, term dates.
  • Prices, sold out, new Stripe links.
  • Blog posts, photos, testimonials.

When you message me

Send three things

  1. The page you were looking at, or its address.

  2. What you asked Claude, copied from the chat.

  3. A screenshot of what looks wrong.
